# java-racingcar-precourse

# 자동차 경주

## 프로젝트 소개

- 사용자가 입력한 자동차 이름과 시도 횟수를 바탕으로, 0-9 사이의 무작위 값에 따라 전진/정지를 반복하는 자동차 경주 게임입니다.
- MVC 패턴을 활용하여 객체지향적 설계를 진행하였습니다.

## 주요 기능 목록

### 핵심 기능

- [ ] 경주할 자동차 이름 입력 받기

- [ ] 시도할 횟수 입력 받기

- [ ] 각 자동차는 0-9 사이의 무작위 값이 4 이상일 경우 1칸 전진

- [ ] 입력된 횟수만큼 경주 라운드 반복

- [ ] 각 라운드마다 자동차의 현재 위치를 -로 표시하여 출력

- [ ] 가장 많이 전진한 자동차를 우승자로 선정 (공동 우승 가능)

- [ ] 최종 우승자 출력

### 예외 처리

IllegalArgumentException을 발생시켜 애플리케이션을 종료

- 자동차 이름 관련 예외 처리

    - [ ] 이름 길이 5자 초과 시 예외 처리

    - [ ] 비어있는 이름 포함 시 예외 처리

        - [ ] 아무런 입력이 없을 때

        - [ ] 연속된 쉼표 입력 시

        - [ ] 쉼표 앞이나 뒤가 비어 있을 때

    - [ ] 중복 이름 입력 시 예외 처리

    - [ ] 공백이 포함된 이름 입력 시 예외 처리


- 시도 횟수 입력 관련 예외 처리

    - [ ] 시도 횟수에 자연수가 아닌 값 입력 시 예외처리

    - [ ] 공백만 입력 시

    - [ ] 문자 입력 시

    - [ ] 자연수가 아니면 예외 처리
        - [ ] 음수 입력 시

        - [ ] 0 입력 시

        - [ ] 소숫점 있는 숫자 입력 시

## 프로젝트 구조

MVC 패턴에 따라 아래와 같이 파일을 구성하였습니다.

```
src
└── main
    └── java
        └── racingcar
            ├── Application.java
            ├── controller
            │   └── RacingGameController.java
            ├── view
            │   ├── InputView.java          
            │   └── OutputView.java         
            └── model
                ├── Car.java
                ├── Cars.java
                ├── SplitCarName.java
                └── RaceWinnerFinder.java
```

## 테스트

- 자동차 이름 관련 예외테스트

    - 이름_5자_초과_예외_테스트: 5자 이상 입력 시 예외 발생 확인.
    - 이름_미입력_예외_테스트: 자동차 이름으로 "" (엔터) 입력 시 예외 발생 확인.
    - 공백_이름_스페이스_입력_예외_테스트: 자동차 이름으로 " " (공백) 입력 시 예외 발생 확인.
    - 공백_이름_연속_쉼표_예외_테스트: 연속적인 쉼표 입력 시 예외 발생 확인.
    - 이름_앞_쉼표_예외_테스트: 맨 앞 쉼표 입력 시 예외 발생 확인.
    - 이름_뒤_쉼표_예외_테스트: 맨 뒤 쉼표 입력 시 예외 발생 확인.
    - 이름_중복_예외_테스트: 중복된 이름 입력 시 예외 발생 확인.
    - 이름_공백_포함_예외_테스트: 공백이 포함된 이름 입력 시 예외 발생 확인.

- 시도 횟수 관련 예외
    - 횟수_공백_스페이스_입력_예외_테스트: 시도 횟수로 " " (공백) 입력 시 예외 발생 확인.
    - 횟수_문자_입력_예외_테스트: 횟수로 문자 입력 시 예외 발생 확인.
    - 횟수_0_입력_예외_테스트: 횟수로 0 입력 시 예외 발생 확인.
    - 횟수_음수_입력_예외_테스트: 횟수로 음수 입력 시 예외 발생 확인.
    - 횟수_소수점_입력_예외_테스트: 횟수로 소숫점 입력 시 예외 발생 확인.
